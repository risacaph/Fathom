# Security Policy

## Supported Versions

Security fixes are applied to the latest version only.

## Reporting a Vulnerability

Please report vulnerabilities privately via this repository's GitHub Security Advisories
("Report a vulnerability" under the **Security** tab).

Fathom is a fork of [Kavita](https://github.com/Kareadita/Kavita) (GPL-3.0). Vulnerabilities that
originate in upstream code may also be reported to the Kavita project.

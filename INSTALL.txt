How to Install (Fathom)
1. Unzip the archive to a directory that is writable. On Windows, do not place it in Program Files.
2. (Linux only) chmod/chown so Fathom can write to the directory you placed it in.
3. Run the Fathom server executable.
4. Open localhost:5000 and set up your account and libraries in the UI.

How to Update
1. Copy everything but the config/ directory over the old install. Restart Fathom.
